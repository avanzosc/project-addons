========================
Project Kanban Name Wrap
========================

Overview
========

The **Project Kanban Name Wrap** module improves the readability of project
and task names in their kanban views. By default, Odoo truncates long names
with an ellipsis, forcing users to hover over each card to read the full name.
This module makes the title wrap to up to two lines so that long names remain
visible without interaction.

Features
========

- Project kanban (``project.project``): the project name wraps to a maximum
  of two lines instead of being truncated.
- Task kanban (``project.task``): the task title wraps to a maximum of two
  lines instead of being truncated.
- No behavioural changes: only visual styling via SCSS.

Configuration
=============

No special configuration is needed after installing the module.
