===========================
Project task estimated cost
===========================

* In project task new fields "Sale line product", "Sale line quantity",
  "Sale line sale price". These are calculated fields, when a sales order line
  is selected in the task, but modification is allowed.
  
* These new fields are also defined in project tasks: "Product Cost",
  "Sale Subtotal", "Total Cost", and "Profit".
